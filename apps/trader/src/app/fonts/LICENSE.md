Fonts in this folder are derived from OFL-1.1 fonts served by Google Fonts and instanced with fontTools to the axis
ranges the website uses (no glyph or outline changes):

- jbmono-k2-latin.woff2 — JetBrains Mono (JetBrains), SIL Open Font License 1.1; wght 500–700

The font files in ../_og are unmodified Google Fonts files (Inter Tight Medium and SemiBold as WOFF,
JetBrains Mono SemiBold as TTF), SIL Open Font License 1.1, used only to render the Open Graph images at build time.
The website itself loads Inter Tight (OFL 1.1) through next/font/google, self-hosted at build time.
