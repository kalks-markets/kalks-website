Fonts in this folder are derived from OFL-1.1 fonts served by Google Fonts and instanced with fontTools to the axis
ranges the website uses (no glyph or outline changes):

- archivo-k2-*.woff2 — Archivo (Omnibus-Type), SIL Open Font License 1.1; wdth 108–125, wght 700–800
- jbmono-k2-latin.woff2 — JetBrains Mono (JetBrains), SIL Open Font License 1.1; wght 500–700

The static TTFs in ../_og are unmodified Google Fonts files (Archivo Expanded ExtraBold, Instrument Sans Medium,
JetBrains Mono SemiBold), SIL Open Font License 1.1, used only to render the Open Graph images at build time.
